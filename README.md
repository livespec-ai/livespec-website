# website
Livespec website: <https://livespec-ai.org>

## Admin consoles

Where `livespec-ai.org` is managed (each needs the maintainer's login):

- [Cloudflare](https://dash.cloudflare.com/?to=/:account/livespec-ai.org): DNS records, SSL/TLS, redirect rules
- [Namecheap](https://ap.www.namecheap.com/domains/domaincontrolpanel/livespec-ai.org/domain): domain registration and nameservers
- [Google Search Console](https://search.google.com/search-console?resource_id=sc-domain%3Alivespec-ai.org): Domain property and sitemap
- [GoatCounter](https://livespec-ai.goatcounter.com/): visit analytics (site code `livespec-ai`)

Pull requests land on main through the livespec-ai merge queue (ruleset master-incident-recovery-bypass); ci-green is the required check.
